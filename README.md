# 七星追剧 - Qixing Zhuiju

基于 Electron 的 Windows 桌面影视播放应用，支持苹果CMS资源站的视频播放，最新版本支持磁力链和P2P播放。

## 🚀 快速开始

### 开发环境

```bash
# 使用pnpm（推荐）
pnpm install       # 安装依赖
pnpm start         # 启动开发服务器

# Windows批处理启动
dev.bat            # 开发启动器
```

### 编译发布

```bash
# 使用pnpm
pnpm run pack      # 推荐：使用electron-packager编译
pnpm run dist      # electron-builder编译
```

#### 智能编译器（Windows批处理）

```powershell
# 交互式菜单（推荐）
.\build.bat

# 直接指定模式
.\build.bat quick    # 快速编译
.\build.bat full     # 完整编译
.\build.bat portable # 便携版Node.js编译
.\build.bat test     # 环境兼容性测试
```

## 📦 编译输出

编译完成后，可执行文件位于：

```text
dist/七星追剧-win32-x64/七星追剧.exe
```

## ⚡ 功能特性

### 🎬 核心播放功能

- ✅ **多站点支持** - 苹果CMS API，支持JSON/XML格式
- ✅ **视频搜索** - 关键词搜索和分类浏览
- ✅ **在线播放** - 支持m3u8格式，基于HLS.js引擎
- ✅ **播放历史** - 自动记录观看历史和播放进度
- ✅ **自动播放** - 智能播放下一集功能
- ✅ **多窗口** - 独立播放器窗口，支持全屏播放
- ✅ **窗口置顶** - 播放器窗口可设置为始终在最前面
- ✅ **投屏功能** - 支持DLNA投屏到电视等大屏设备

### 🧲 磁力播放（新增）

- 🆕 **磁力链播放** - 支持磁力链接直接播放
- 🆕 **文件选择** - 磁力解析后可选文件播放
- 🆕 **P2P加速** - 边下边播，智能P2P加速
- 🆕 **阶段进度** - 6阶段进度实时反馈
- 🆕 **外链播放** - 支持URL和本地文件播放

### 💬 弹幕互动功能

- ✅ **实时弹幕** - 基于WebSocket的实时弹幕系统
- ✅ **多彩弹幕** - 7种颜色、3种大小的弹幕样式
- ✅ **智能房间** - 根据视频自动分配弹幕房间
- ✅ **双弹幕模式** - 支持实时弹幕和时间轴弹幕
- ✅ **一键开关** - 可随时开启/关闭弹幕显示

### 🛠️ 站点管理功能

- ✅ **站点配置** - 添加/编辑/删除视频站点
- ✅ **线路屏蔽** - 支持屏蔽指定播放线路
- ✅ **线路别名** - 自定义线路显示名称
- ✅ **智能过滤** - 自动忽略被屏蔽的播放线路

### 💾 数据管理功能

- ✅ **配置导出** - 一键导出所有设置和数据
- ✅ **配置导入** - 支持合并/覆盖两种导入模式
- ✅ **数据迁移** - 跨设备快速同步配置

### 🎨 界面体验

- ✅ **玻璃拟态** - v1.5.0全新玻璃拟态设计系统
- ✅ **响应式设计** - 适配不同屏幕尺寸
- ✅ **深色主题** - 护眼的暗色界面
- ✅ **自定义标题栏** - 无边框透明窗口设计

## 🛠️ 技术栈

- **Electron 27.x** - 桌面应用框架
- **HLS.js** - 视频播放引擎，支持m3u8流媒体
- **WebTorrent** - 磁力链接P2P下载播放
- **Axios** - HTTP请求库
- **WebSocket (ws)** - 实时通信，支持弹幕互动
- **LocalStorage** - 本地数据存储
- **pnpm** - 包管理器

## 📄 使用说明

### 基础操作

1. **添加站点** - 设置页面 → 站点管理 → 添加站点
2. **搜索视频** - 主页面输入关键词搜索
3. **播放视频** - 点击视频海报 → 选择剧集播放
4. **磁力播放** - 外链页面粘贴磁力链接，选择文件播放
5. **查看历史** - 设置页面 → 播放历史

### 高级功能

- **线路别名** - 设置页面 → 线路设置 → 添加别名
- **弹幕互动** - 播放器内按回车键打开弹幕输入框
- **DLNA投屏** - 播放器控制栏投屏按钮，投屏到智能电视
- **屏蔽线路** - 站点管理 → 编辑站点 → 屏蔽线路
- **数据备份** - 设置页面 → 导出/导入配置
